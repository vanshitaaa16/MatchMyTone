# ⚡ Quick Start Guide (TL;DR)

## If You Already Have Android Studio:

1. **Start Emulator:**
   - Open Android Studio
   - Click phone icon → Start your emulator

2. **Build App:**
   ```bash
   cd "C:\Users\VANSHITA SHAH\MatchMyTone"
   npx expo prebuild --clean
   # Answer "yes" to Git question
   npx expo run:android
   ```

3. **Done!** App will install and launch automatically.

---

## If You DON'T Have Android Studio:

1. **Download & Install Android Studio** (30 min)
   - https://developer.android.com/studio
   - Install with default settings

2. **Create Emulator** (30-60 min)
   - Android Studio → Virtual Device Manager
   - Create Device → Pixel 5 → Download API 33 → Start

3. **Build App** (20-30 min first time)
   ```bash
   cd "C:\Users\VANSHITA SHAH\MatchMyTone"
   npx expo prebuild --clean
   npx expo run:android
   ```

4. **Done!**
